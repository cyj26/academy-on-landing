# academy-on-landing

Academy ON 수요 검증용 랜딩페이지. `main`에 push하면 GitHub Pages로 자동 배포된다.

- 공개 주소: https://cyj26.github.io/academy-on-landing/ (이 링크 하나만 공유하면 휴대폰은 자동으로 `/mobile/`로 이동. `?view=pc`로 PC 버전 고정)
- 응답 수신: 구글 시트 "응답" 탭 하나 (한 사람당 한 줄). `apps-script/README.md` 참고
- 유입 경로 추적: 링크에 `?utm_source=kakao&utm_campaign=beta1`처럼 붙이면 시트에 함께 기록된다.
