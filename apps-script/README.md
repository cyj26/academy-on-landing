# 설문 응답 수신 (구글 시트)

응답은 시트의 **"응답" 탭 하나**에 쌓인다. 한 사람(응답자 ID)당 한 줄이며, 다시 응답하면 그 줄이 최신 답으로 바뀌고, 연락처를 남기면 같은 줄에 채워진다.

## 처음 설정
1. 구글 시트에서 **확장 프로그램 → Apps Script**를 연다.
2. 코드를 모두 지우고 `Code.gs` 내용을 붙여 넣은 뒤 저장한다.
3. **배포 → 새 배포 → 웹 앱** (실행 사용자: 나, 액세스: 모든 사용자). 발급된 URL을 `index.html`, `mobile/index.html`의 `FORM_ENDPOINT`에 넣는다.

## 코드를 바꾼 뒤 (URL 유지)
**배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**. "새 배포"를 누르면 URL이 바뀌니 주의.

## 예전 탭 정리 (2026-10-23, 한 번만)
Apps Script 편집기 위쪽 함수 목록에서 `setupOnce`를 고르고 **실행**. 예전 탭(구매의향·상세응답·연락처·우리집요금·시트1)의 실제 응답을 "응답" 탭으로 옮기고 시험 응답과 예전 탭을 지운다. 되돌리려면 시트의 **파일 → 버전 기록**.

## 테스트할 때
자동 테스트는 `script.google.com` 요청을 막고 돌린다 (실제 시트에 시험 응답이 쌓이지 않게).
